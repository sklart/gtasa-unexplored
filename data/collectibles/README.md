# GTASA Unexplored collectible pack

Generated by `build_gtasa_homebrew_pack.py`.

## Contents

- 320 canonical collectible records.
- English and Russian descriptions.
- Canonical world coordinates.
- Explicit runtime lookup strategy.
- Source/provenance metadata.
- Optional optimized image media.

Profile:
- format: jpeg
- maximum photo size: 960x540
- quality: 85
- map images included: no
- Wiki tag graphics included: no

Images were converted from the local consolidated master dataset.

## Switch runtime location

Recommended install target:

```text
sdmc:/switch/gtasa-unexplored/collectibles/
```

The application should load only the selected collectible image. Do not preload
all images into SDL textures.

## IDs and lookup

`canonical_id` is the Wiki/catalogue identity used for filenames and localization.

Tags additionally contain `lookup.save_order_id`, because the GTA save TAGS array
uses save order rather than Wiki numbering.

Snapshots, Horseshoes, Oysters and Stunt Jumps use
`lookup.strategy = nearest_world_coordinate`. Do not bind metadata to the
transient ordinal of the current Missing pickup list.

## Third-party media

`credits.json` preserves the source URLs and file metadata returned by the source
wiki. A blank file-specific license field must not be interpreted as permission to
redistribute the image. Keep media distribution separate from the MIT source code
unless the rights for the concrete files have been reviewed.
