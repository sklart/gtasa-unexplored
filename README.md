# GTASA Unexplored

Nintendo Switch homebrew-companion для **Grand Theft Auto: San Andreas — The Definitive Edition**. Приложение читает сохранение выбранного пользователя **только для чтения** и показывает на интерактивной карте состояние пяти типов коллекционных объектов.

## Целевая версия

- Nintendo Switch title ID: `010065A014024000`.
- GTA: San Andreas — The Definitive Edition, семейство сохранений **1.1x / 1.112+**.
- Классическая GTA SA и старый DE 1.0x не поддерживаются.
- Игровой save монтируется только через `fsdevMountSaveDataReadOnly()`.
- Если GTA удерживает save archive открытым, используется последняя резервная копия на SD.

## Объекты

Всего **320** объектов:

- 100 Gang Tags;
- 50 Snapshots;
- 50 Horseshoes;
- 50 Oysters;
- 70 Unique Stunt Jumps.

Поддерживаются режимы отображения:

- **Missing** — только ненайденные;
- **Completed** — только найденные;
- **All** — полный набор.

Для Tags и Stunt Jumps состояние хранится непосредственно в save. Для Snapshots/Horseshoes/Oysters активные `PICKUPS` являются точным списком Missing; Completed восстанавливается через встроенный канонический каталог 50+50+50 координат. Сопоставление работает fail-closed: если хотя бы одна активная запись не сопоставляется однозначно, приложение не придумывает координаты Completed для этой категории и продолжает показывать достоверный Missing.

## Возможности

- Перемещение карты левым stick и касанием с перетаскиванием пальцем; щипок масштабирует, двойное касание сбрасывает вид.
- Фильтры пяти категорий и независимый фильтр POI (его состояние сохраняется в `config.ini`).
- `Missing / Completed / All` с сохранением выбранного режима.
- Стабильные номера 1–50 для трёх pickup-категорий при подтверждённом сопоставлении.
- Быстрый переход к предыдущему/следующему видимому объекту.
- Выбор Nintendo-профиля и GTA save slot.
- RU/EN интерфейс.
- DE-header diagnostics и проверка complemented-MD5 для 1.112+.
- Автоматический `diagnostics.txt` при ошибках обнаружения/разбора save.
- Временные отметки при работе со stale backup, раздельные по профилю и слоту.
- Внешние map-pack'и; карты Rockstar/Fandom не входят в NRO/исходный архив.
- Переключение подложки ↑/↓ без изменения центра и масштаба.
- Горячая перезагрузка `maps.ini` и файлов карт без перезапуска homebrew.

## Collectible details

Для всех 320 объектов приложение содержит скомпилированные русские и английские
описания и каноническое сопоставление с save. Повторно нажмите **A** на уже
выбранной метке (либо повторно коснитесь её), чтобы открыть карточку. Карточка
лениво загружает одну оптимизированную фотографию места с SD; отсутствие пакета
изображений не мешает карте и чтению сохранений. **B** закрывает карточку,
**↑/↓** прокручивают текст, **L3/R3** переключают видимые объекты. Для
перекрывающихся меток используйте **ZL + L3/R3**.

## POI: места и достопримечательности

Пакет содержит 80 карточек POI с фото и RU/EN-описаниями. На карте показываются
только координаты, прошедшие консервативную проверку: конкретные объекты с
`cross_checked_xyz` и протяжённые объекты с явно обозначенным
`representative_2d` (у них нет фиктивного Z). POI без подтверждённой точки
остаются в `coordinate_audit.json`, но не получают маркер. Оранжевый pin — POI;
жёлтый pin означает репрезентативную, а не телепорт-координату. Нажмите A или
коснитесь pin повторно, чтобы открыть карточку с фотографией.

## Installation

Рекомендуемый способ — распаковать `gtasa-unexplored-switch.zip` в корень SD.
В результате должны появиться:

```text
sdmc:/switch/gtasa-unexplored/
├── gtasa-unexplored.nro
└── collectibles/
    ├── collectibles.json
    ├── credits.json
    ├── manifest.json
    ├── media.ini
    └── images/
└── poi/
    ├── poi.json
    ├── coordinate_audit.json
    └── images/
```

Фотографии collectibles не встраиваются в NRO: они остаются отдельным media-pack
на SD, а пять пользовательских PNG-пиктограмм встраиваются в интерфейс NRO.

## Map-pack v1

Подготовленные отдельно карты копируются в:

```text
sdmc:/switch/gtasa-unexplored/maps/
```

`maps.ini` для format 1 обязан содержать:

```ini
[pack]
format=1
projection=sa-world-v1
canvas_size=2048
```

Для совместимости со старыми пакетами также допускается `canvas=...`; если
заданы оба поля, используется `canvas_size`.

Для отдельной ручной калибровки конкретного `[map]` можно задать
`world_left`, `world_right`, `world_top`, `world_bottom`. По умолчанию это
`-3000`, `3000`, `3000`, `-3000`; параметры меняют только проекцию данного
слоя и применяются одинаково к рендеру, касанию и выбору маркера.

Поддерживаются квадратные подложки от **512×512 до 4096×4096**; для Switch
рекомендуется **2048×2048**. Все подложки должны быть north-up и зарегистрированы на один мир:

- left = X -3000;
- right = X +3000;
- top = Y +3000;
- bottom = Y -3000.

Шаблон содержит пять записей: Terrain, Official High-Res, Mobile, Definitive Edition и Geographic Regions. Самих изображений в шаблоне нет.

Проверка готового пакета на PC:

```bash
python tools/validate_map_pack.py path/to/maps
```

Валидатор проверяет manifest и фактические размеры каждого установленного изображения.

## Управление

### Карта

- **левый stick / touch drag** — перемещение по карте (drag доступен и в полноэкранном режиме);
- **L / R** — масштаб;
- **↑ / ↓** — предыдущая / следующая подложка;
- **↑** — `Missing → Completed → All`;
- **← / →** — предыдущий / следующий save slot;
- **L3 / R3** — предыдущий / следующий видимый collectible;
- **ZL + L3 / R3** — предыдущая / следующая метка в группе перекрытия;
- **ZR + R3 / touch двумя пальцами** — скрыть/показать правую панель;
- **A / touch tap** — выбрать ближайший объект; повторное касание выбранной метки открывает карточку;
- **B** — снять выбор;
- **X** — открыть фильтры;
- **Y** — перечитать map-pack;
- **−** — заново выбрать профиль;
- **+** — выход.

### Фильтры

- **↑ / ↓** — категория;
- **A** — включить/выключить категорию;
- **ZL** — RU/EN (только в окне Filters);
- **X** — закрыть.

Пункт **POI** включает и выключает все маркеры достопримечательностей независимо
от collectibles. Значки collectibles — встроенные PNG с лёгкой тенью; найденные
объекты в режиме полного списка отображаются полупрозрачно, а выбранный значок
слегка увеличивается и получает тонкое светлое выделение.

## PC-инспектор save

После host-сборки доступен инструмент `inspect-save`. Из исходников его можно собрать тем же набором файлов, который использует `tools/run_host_tests.sh`.

Краткий отчёт:

```bash
inspect-save GTASAsf1
```

Полный список объектов:

```bash
inspect-save GTASAsf1 --objects
```

Машиночитаемый отчёт со всеми объектами и reliability-флагами (тот же schema=1 формат, который Switch пишет в `saveinfo.json`):

```bash
inspect-save GTASAsf1 --json > save-report.json
```

## Сборка

Требуются devkitPro/devkitA64, libnx и portlibs:

```text
switch-sdl2
switch-sdl2_ttf
switch-sdl2_image
```

Сборка:

```bash
make -j2
```

Host regression:

```bash
./tools/run_host_tests.sh
./tools/run_sanitizer_tests.sh
```

GitHub Actions сначала запускает host + ASan/UBSan, затем выполняет devkitA64-сборку.

## Статус проверки

Parser, checksum, corrupted-save cases, полный каталог объектов, save-order Tags, map math, map-pack tooling, source invariants и Switch UI syntax проверяются host-тестами. Версия остаётся **hardware RC**, пока конкретный NRO не будет собран devkitA64 и проверен на физическом Nintendo Switch с актуальным DE 1.112+ save.
